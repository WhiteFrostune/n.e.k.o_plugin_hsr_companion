# 星铁游戏搭子 0.8.2 使用说明

> **公开测试提示：** 当前版本仍可能认不出角色、混淆特殊场景、遗漏工具调用或在不合适的时机主动搭话。
> 角色身份以清晰角色名与数据库结果为准；没有可靠证据时应返回“不确定”。完整列表见 [公开测试状态与已知问题](../TESTING_STATUS.md)。

## 最简单的使用方式

1. 打开“星铁游戏搭子 0.8.2”面板。首次使用时插件会在插件包外自动准备资料组件。
2. 面板显示“完整资料已就绪”后，点击“开始自动观察”。
3. 切回《崩坏：星穹铁道》正常游玩，之后直接和 N.E.K.O 聊天即可。

资料组件准备失败时，88 名角色的严格身份名单仍然有效，猫娘不会把未收录名字编成
真实角色；但技能、培养和装备问题会明确提示资料未就绪，不靠模型旧知识硬答。面板
可以一键重试。

## 让猫娘知道你正在做什么

开启自动观察后，插件会先判断页面，再读取页面限定区域。目前支持：

- 角色详情；
- 队伍编成；
- 回合制战斗界面；
- 剧情对话；
- 跃迁；
- 奖励或结算；
- 地图或任务；
- 加载画面。

不属于受支持页面、文字不清晰或证据不足时，插件会显示“暂时无法判断”，不会把
模型猜测冒充成事实。已验证状态五分钟后自动过期。由于星铁是回合制加箱庭探索，
插件采用低频、稳定页面识别，不持续追踪高速目标。

自动观察只在星铁窗口处于前台时读取画面。切到其他应用或最小化游戏后会暂停；画面
仅在内存中压缩、去重和 OCR，不写入磁盘。N.E.K.O 接收最新一帧只读视觉上下文和数据库约束过的结构化结果；排队中的旧帧会被新帧覆盖。

角色识别结果确认前不会写入正式档案。需要导入角色列表或自动观察不可用时，可展开“手动提供截图”。

## 直接聊天也可以

开启星铁陪玩后，把角色列表截图直接发给 N.E.K.O，并说：

> 帮我识别这张角色列表，先别保存，认完让我确认。

N.E.K.O 会调用插件暂存识别结果。你说“确认保存”后，插件才会更新档案。

## 认错了怎么办

- 视觉认错：在待确认卡片里填写“识别成了谁”和“实际是谁”，点击“记住这次纠正”。插件会优先把纠错绑定到当前页面的角色区域指纹。
- 语音同音字：展开“语音或聊天名字纠错”，选择“语音”，填写识别文本和正确角色名。常见写法直接由内置语音别名识别，新的同音写法可保存成玩家别名。
- 如果错误文本本身也是一个真实角色名（例如把爻光认成知更鸟），插件只记录为需要新证据确认的歧义，不会把所有“知更鸟”都改成“爻光”。视觉纠错只有绑定到当前角色名区域时才会自动应用。

## 重要说明

- 自动观察和手动截图优先经过 N.E.K.O 内置的共享 RapidOCR；插件不保存原始图片。
- 插件只保存不可逆的角色区域指纹，用来限定视觉纠错的适用范围。
- 角色字段采用固定版本注册表严格校验，不存在或未收录的名字无法写入档案；插件不会做模糊猜测。
- 模型提交的游戏状态只是未验证线索，不能覆盖插件本地验证状态。
- 外部资料组件是固定版本快照，来源和许可见第三方数据说明；之后新版本的内容仍需更新数据修订号。
- 玩家档案可以随时修改，并可在面板的“插件设置”中清空。
- 插件不会修改或操作游戏客户端。
- “结束本次陪玩”会撤回星铁专用语境，不影响 N.E.K.O 的其他聊天。
- 插件记录不等同于 N.E.K.O 的长期情感记忆。
